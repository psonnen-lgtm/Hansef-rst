# Nowgorod – Phase 0.7b

Eigene KI-erzeugte Hansefürst-Komposition nach der freigegebenen Lübecker Stilreferenz, keine Grafik eines fremden Spiels. Künstlerische Stadtansicht um 1350, keine exakte historische Rekonstruktion. Unbearbeitetes PNG-Original; WebP wird ausschließlich verlustfrei kodiert, Bildgleichheit in encoding.json.

Eingänge, Wege und Wasser sind für diese Komposition in `../city-layouts.json` festgelegt. Keine wirtschaftliche Bedeutung der sichtbaren Lasten/Schiffe.
